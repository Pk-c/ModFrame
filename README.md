# ModFrame

A small Windows utility for managing files and installing mods on Steam Frame over USB.

# How to use ModFrame

1. On your Steam Frame, enable Developer Mode and USB Debugging.
2. Connect the Steam Frame to your PC using a USB data cable.
3. Launch ModFrame.exe.
4. Accept the USB debugging authorization request inside the headset.
5. Wait for the connection indicator to turn green.

# File manager

- Double-click a folder to open it.
- Use Upload files or Upload folder to copy mods to the current folder.
- Use Download to copy selected files back to your PC.
- Use Rename, New folder, or Delete to manage files.
- You can also drag files and folders into ModFrame.

# Install a ZIP mod

1. Open the mod’s destination folder on the Steam Frame.
2. Click Unzip here.
3. Select the ZIP archive.
4. ModFrame extracts it on the PC and uploads its contents into the open folder.
